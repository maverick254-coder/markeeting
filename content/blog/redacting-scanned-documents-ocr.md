Many of the documents that need redaction were never born digital. Signed contracts, faxed forms, archived case files and photographed letters often arrive as scans.

To a computer, a scanned page is a picture. Until text is recognised, there is nothing to search and nothing for a detector to read.

## What OCR adds

Optical character recognition (OCR) turns the image of a page into text that software can work with. For redaction review, that has three practical benefits:

- **Search.** A reviewer can find every occurrence of a name or reference instead of reading each page line by line.
- **Candidate findings.** Where detection is configured, recognised text can be checked for categories of sensitive information, which then go to a reviewer.
- **Text-aligned marks.** Selections can follow recognised words rather than being drawn freehand.

In RedactPlus, OCR can be run on scans and image-based pages when OCR tooling is configured. Pages that already contain real text use that text directly.

## Where OCR needs a second look

Recognition quality depends on the source. Reviewers should slow down when they see:

- **Low-quality scans.** Faint, skewed or compressed pages produce more recognition errors.
- **Handwriting.** Notes in margins and handwritten forms are often recognised poorly, or not at all.
- **Stamps, signatures and logos.** These are visual elements, not text, and need area redactions.
- **Tables and columns.** Text can be read in an unexpected order, which affects search and detection.
- **Unusual characters.** Account numbers and references can be misread, for example a zero as the letter O.

A missed recognition means a missed search result. The text is still visible on the page even when the software did not read it.

## Combine recognised text with manual marks

The most reliable approach uses both:

1. Run OCR and review the candidate findings it makes possible.
2. Search for names and references you already know are present.
3. Read through each page for anything recognition may have missed.
4. Draw area redactions over handwriting, signatures and other visual content.

RedactPlus supports text and area redactions on the same page, so recognised and visual content can be handled in one review.

## Check the output

As with any redaction, finish by opening the exported copy and inspecting every page. For scans, confirm that each area mark fully covers what it was meant to cover.

OCR makes scanned documents workable. A reviewer's judgment is what makes the result safe to share.
